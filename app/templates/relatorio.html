Instruções para o Relatório Consolidado
Como usar o Relatório Consolidado
1
Arquivos de Chamada: Adicione todos os arquivos Excel de chamadas da unidade escolar
Formato esperado: NOME_ESCOLA_DD-MM-AAAA_PERIODO_NOME_EQUIPE.xlsx
2
Arquivo de Análise: Inclua o arquivo com análise de frequência dos alunos
Qualquer arquivo que não siga o padrão acima será identificado como análise
3
Relatório Gerado: O sistema criará um arquivo Excel com 3 abas:
  • CHAMADAS: Dados consolidados de todas as visitas
  • ANÁLISE: Informações de frequência e status dos alunos
  • MONITORAR: Lista prioritária de alunos para acompanhamento
