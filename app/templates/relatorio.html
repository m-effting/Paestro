Instruções para o Relatório Consolidado
1
Selecione os Arquivos: Carregue todos os arquivos de Chamadas (visitas) e o arquivo de Análise da unidade escolar.
O sistema identifica automaticamente qual é qual.
2
Escolha Quais arquivos gerar:
  • Excel Relatório Consolidado: Gera um arquivo completo com 4 abas:
    • CHAMADAS: Histórico detalhado de todas as visitas realizadas na unidade.
    • MONITORAR: Lista automática de alunos prioritários para Busca Ativa.
    • ANÁLISE: Espelho formatado da planilha de análise original.
    • SITUAÇÃO ALUNOS BUSCA ATIVA: Lista interativa para controle (Ativo/Transferido/Infrequente) e contagem automática.
  • PDF de Encaminhamento para Unidade: Gera um documento oficial, listando apenas os alunos que precisam de busca ativa imediata.
3
Baixe o Resultado: Após o processamento, um arquivo ZIP contendo os documentos gerados será baixado automaticamente.
